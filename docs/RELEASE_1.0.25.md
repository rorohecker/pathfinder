# Pathfinder 1.0.25

- **File filters:** open the Filters toolbar button or press `Ctrl+Shift+G`. Combine filenames, extensions such as `.pdf, .sys`, file categories, sizes, and modification dates. Each pane filters independently, with one-click reset.
- **Clearer toolbar:** address and search fields no longer overlap at medium window widths. Breadcrumbs and two-line grid/gallery filenames are easier to read.
- **Removed ineffective thumbnail controls:** Smaller/Larger thumbs changed spacing without resizing thumbnails. Their removal also frees toolbar space.
- **Windows content search fix:** indexed files are found correctly when a folder is addressed through a Windows short-name alias.

Download `Pathfinder_1.0.25_x64-setup.exe` for the standard Windows installer, or use `Pathfinder_1.0.25_x64_en-US.msi` for Windows Installer deployment.
