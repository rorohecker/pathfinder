# Pathfinder 1.0.27

- **Tighter toolbar:** navigation and view buttons use consistent spacing, with no empty slots reserved for hidden actions. Search help, saved searches, and reset sort remain available in More.
- **Smaller search field:** search is capped at 192 logical pixels, leaving more room for folder paths. Typing or editing the address no longer shifts the toolbar controls.
- **Sort controls fit correctly:** all four sort options stay inside their container.
- **Compact filters:** wide panes arrange name and extension side by side, with kind, size, and date on the next row. Narrow and dual panes keep readable stacked controls.
- **Simple mode:** the second toolbar row uses evenly sized controls across the available width.

Download `Pathfinder_1.0.27_x64-setup.exe` for the standard Windows installer, or `Pathfinder_1.0.27_x64_en-US.msi` for Windows Installer deployment.
