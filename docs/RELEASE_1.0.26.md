# Pathfinder 1.0.26

- **Search stays in the toolbar row:** both normal and simple modes keep a search field at supported window sizes, including when the sidebar is widened.
- **Responsive toolbar:** narrower windows move view and search options into the More menu, leaving room for the address bar and search. Wider windows keep the view buttons on the row.
- **No overlapping text:** search placeholders shorten and elide within their fields, and address/search geometry updates together while resizing or editing the address.
- **Search shortcut:** focusing search clears the selection bar so the search field is visible and ready to type into.

Includes the file-type, category, size, and modification-date filters from 1.0.25. Open Filters or press `Ctrl+Shift+G`.

Download `Pathfinder_1.0.26_x64-setup.exe` for the standard Windows installer, or use `Pathfinder_1.0.26_x64_en-US.msi` for Windows Installer deployment.
